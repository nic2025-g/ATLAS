# 02 — Analyse métier

## Cycle de vie générique d'un projet

Les 4 projets pilotes suivent exactement la même logique. Ce modèle générique est la base du schéma de données ATLAS.

```
Programme (définition du besoin)
         │
         ▼
       AVP
  (Avant-Projet)
  Budget ±30%
         │
         ▼
       PRO
     (Projet)
  Budget ±10%
         │
         ▼
  Consultation / ACT
  (Appel d'offres)
   Prix du marché
         │
         ▼
     Travaux / DET
  (Exécution + suivi)
  Situations mensuelles
  Avenants éventuels
         │
         ▼
    Réception / AOR
    Coût final TTC
    Indicateurs DD
```

## Structure commune aux 4 projets

### Allotissement systématique en lots variant de 1 a 5

| Lot | Contenu | Entreprises mandataires observées |
|-----|---------|----------------------------------|
| **Lot 1** | Voirie, espaces publics et réseaux (VRD) | SO.TRA.VER (Vedène) |
| **Lot 2** | Espaces verts et aménagements paysagers | TERRA PAYSAGE SUD (Avignon) |
| **Lot 3** | Éclairage public et réseaux secs | VRD MÉDITERRANÉE (Avignon) |

### 5 financeurs potentiels systématiques

Chaque projet sollicite les mêmes 5 organismes avec les mêmes taux plafonds :

| Organisme | Nature | Taux |
|-----------|--------|------|
| Département de Vaucluse | AEP | 5% |
| Agence de l'Eau RMC | EU | 8% |
| Agence de l'Eau RMC volet pluvial | EP | 7% |
| Région Sud | EP + aménagement | 5% |
| État DETR | AEP, EU, aménagement | 6% |

### 16 indicateurs de développement durable

Chaque projet intègre une fiche de 16 indicateurs DD avec valeurs cibles (PRO) et valeurs constatées (AOR). Catégories : Bas-Carbone, Biodiversité, Social.

### Risques récurrents

| Code | Risque | Gravité | Probabilité |
|------|--------|---------|-------------|
| R1 | Géotechnique (fondations, remblais) | GRAVE | 50–70% |
| R2 | Foncier (servitudes, conventions) | MOYENNE | 80–100% |
| R11 | Hausse des prix matériaux | GRAVE | 50% |
| R12 | Aléa chantier imprévu | TRÈS GRAVE | 80% |
