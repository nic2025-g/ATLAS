# Décisions métier — Réunion du 28/08/2026

## Risques
Les risques sont sortis du périmètre MVP.
Ils ne doivent plus apparaître dans le dashboard final.

## Délais
Aucun retard n’est calculé pour les opérations en cours.

Pour les opérations terminées :
- date_debut_prevue
- date_fin_prevue
- date_fin_reelle

Le retard pourra être exprimé :
- en jours ;
- et éventuellement en pourcentage de la durée initialement prévue.

## Budget
Pour la synthèse élus :
- budget investi = somme des budgets FAISA.

Pour les opérations terminées :
- comparaison entre montant des marchés signés ;
- et montant total réellement payé.

Chaque lot doit donc pouvoir porter :
- montant_marche ;
- montant_total_paye.

## Développement durable
Les indicateurs DD sont conservés.

## Synthèse élus
La page doit rester très synthétique :
- nombre de projets ;
- part terminée / en cours ;
- budget investi ;
- indicateurs DD ;
- carte des opérations ;
- filtres Commune et Opération.

Pas de tableau détaillé au centre de la page.

## Fiche opération
Créer une page détaillée par opération avec :
- commune ;
- maître d’œuvre ;
- localisation cartographique ;
- lots ;
- entreprises ;
- évolution FAISA → Marché ;
- montant payé si opération terminée ;
- indicateurs DD ;
- dates et avancement si les données sont disponibles.
